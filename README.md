# 🦟 Global Malaria Burden Analysis

## An End-to-End Epidemiological Analysis Using WHO Data, Python, and Power BI

---

## 📖 Project Overview

This project presents an end-to-end epidemiological analysis of the global malaria burden using data from the World Health Organization (WHO). The project demonstrates the complete data analysis workflow, including data cleaning, exploratory data analysis (EDA), statistical visualization, epidemiological interpretation, and interactive dashboard development.

The analysis aims to transform raw surveillance data into meaningful public health insights that support evidence-based decision-making.

---

## 🎯 Project Objectives

The main objectives of this project are to:

- Analyze the global burden of malaria.
- Explore temporal trends in malaria indicators.
- Compare malaria burden across countries and WHO regions.
- Perform exploratory data analysis (EDA).
- Develop an interactive Power BI dashboard.
- Generate epidemiological insights.
- Provide evidence-based public health recommendations.

---

## 📂 Dataset

**Source:** World Health Organization (WHO) – Global Health Observatory (GHO)

**Format:** CSV

**Coverage:** Global

The dataset includes malaria indicators reported by countries and WHO regions over multiple years.

## 📈 Dashboard Pages

The Power BI dashboard consists of four interactive pages:

### Executive Dashboard

Provides an overall summary of malaria indicators using KPI cards and key visualizations.

### Geographic Analysis

Explores the spatial distribution of malaria across countries and WHO regions.

### Trends & Forecasting

Analyzes temporal trends in malaria burden over time.

### Public Health Insights & Recommendations

Summarizes key epidemiological findings and evidence-based recommendations.

## 🚀 How to Run the Project

### 1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Malaria-Epidemiological-Analysis.git
```

### 2. Install the required libraries

```bash
pip install -r requirements.txt
```

### 3. Open the Jupyter Notebook

```bash
jupyter notebook
```

### 4. Open the Power BI Dashboard

Open:

```
dashboard/malaria_dashboard.pbix
```

using Microsoft Power BI Desktop.
